# Decilion Insights — Data & Code

Open data, calculations, and methodology behind **[Decilion Insights](https://decilion.com/insights/)** reports.

[Decilion](https://decilion.com) is a global-health consultancy working across the 33 countries of Latin America and the Caribbean, in English, Spanish, and Portuguese. We publish our reports as independent analytical work, and we publish the data and code behind every headline number right here, so anyone can download it, re-run the analysis, and check our numbers. We treat transparency as the strongest form of quality assurance.

Each report folder has a README that maps every headline number to the file it comes from, plus a `reproduce.py` you can run with no dependencies.

## A note on review, and an open invitation

Decilion Insights reports are independent analytical grey literature, not academic peer review. Their authority rests on transparent methods and reproducible data rather than on a reviewer's stamp. In that spirit, we welcome scrutiny: if you find something to correct, have data that sharpens the picture, or want to build on this work, **open an issue** here or write to **j.garcia@decilion.com**. We would genuinely like to hear from you.
