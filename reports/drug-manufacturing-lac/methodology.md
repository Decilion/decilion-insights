# Methodology & Limitations — Pharmaceutical manufacturing capacity in Latin America and the Caribbean

- **Indicator selection & rationale:**
- **API code caveat (IMPORTANT — HS ≠ pharmaceutical use):** There is no clean HS code for "active pharmaceutical ingredient." APIs sit mostly in **Chapter 29 (organic chemicals)** — not Chapter 30 (finished/formulated meds) — plus bulk un-dosed medicaments in **3003**. We initially used **HS 2933** (heterocyclic-N compounds) as a single proxy ("base of many APIs" per the comtrade-pharma curated list). This is imprecise in BOTH directions: 2933 **overstates** (includes non-pharmaceutical heterocyclics — agrochemicals, dyes) and **understates** (omits 2934/2936/2937/2941 and bulk 3003). The **robust** part of the API finding is the **origin concentration in China + India**, which holds across Chapter-29 codes and matches the supply-chain literature. **RESOLVED — adopted the EFPIA authoritative basket.** We use the HS6 API code list from EFPIA,
*Key trade data points on the EU27 pharmaceutical supply chain* (Annex 3), which curates **specific
Chapter-29 subheadings filtered to pharmaceutical use** (cross-checked against end-use code 40100 and
US NAICS 3245/325199) and **explicitly excludes** non-pharma codes (e.g., 293361 melamine, 290381
lindane, 291040 dieldrin). Our basket = **101 HS6 codes** (general Ch29 APIs + 300190 heparins/organo-
therapeutic + 300213 monoclonal antibodies + antibiotics-API 294110/120/130/140/150/190), stored at
`data/clean/api_codes_efpia.csv`. API imports are summed from UN Comtrade **bulk** HS6 data (one file per
country) via `comtrade_pharma_bulk`. The earlier single-code HS2933 figure is **withdrawn** (over-broad:
included non-pharma heterocyclics). Residual caveat: HS still cannot perfectly isolate pharmaceutical use,
and Comtrade lacks the EU end-use overlay — so this is the most defensible HS-based basket, not an exact
API measure; the robust signal is the **China+India origin concentration (53–76% across producers)**.
- **Data sources & vintages:** Trade data from UN Comtrade via the `comtrade-pharma` MCP. **Base year = 2024 (latest available).** Convention: where 2024 is not yet released for a reporter, use its latest available year, labeled as such (Dominica & Saint Vincent and the Grenadines → 2023). For the 5 chronic non-reporters (Cuba, Haiti, Venezuela, Saint Lucia, Saint Kitts & Nevis), substitute **mirror (partner-reported) data** via `comtrade_pharma_mirror_check`, flagged. (Health-system context indicators, if used, anchor on ghed/gho/data360 — NOT oecd-health-mcp.)
- **Transformations / normalization:** trade balance = exports − imports; export/import ratio; extra-regional import share (sum of non-LAC partner shares); HHI supplier concentration; RCA (Balassa) for export specialization. Capability typology built from these.
- **Headline number model:** dependency-exposure prize. The SHARE is estimated by two methods (all-partner ~91% volume-weighted, per-market 57–97%; the top-10 method ~97% truncates intra-regional partners and is an upper bound — all-partner supersedes it). The DOLLAR anchor is built **bottom-up**, not by extrapolating the share onto the base: ~US$29bn measured directly from the 10 largest markets → ~US$32–34bn across all 28 reporters (conservative shares on the smaller 18) → **anchor ~US$33bn (lower bound)**. Re-anchored 2026-06-05 after the editorial-board Adversary flagged that the old "US$35–37bn" blended a top-10 share onto the whole base. Detail:
  1. **All-partner method (primary, corrected after cross-model audit):** from Comtrade **bulk** HS6 data, Σ HS30 imports from all LAC-33 partner M49 codes ÷ World (partnerCode 0), per country, then volume-weighted across the 10 largest markets → **~91% extra-regional** (per-market range 57–97%). `dependency_allpartner_2024.csv`.
  2. **Top-10-partner method (upper bound / validation):** summing only top-10 partners gave ~97% (intra-LAC ≈3%) — it TRUNCATES small intra-regional partners and overstates extra-regional dependence (it wrongly implied Brazil/Mexico were ~100% extra-regional). Disclosed as an upper bound; the all-partner figure supersedes it.
  - **Value field:** use Comtrade `primaryValue` (the harmonized value field; `CIFValue` is blank for some reporters, e.g. Mexico). **China+India share:** World partner row (code 0) as denominator, bilateral China(156)+India(699) rows as numerator — not summed together.
  - **Mexico reconciliation:** `compare_countries` returned HS30 imports of US$8.82bn, but the de-duplicated bulk HS6 extract gives US$6.46bn; the bulk figure (clean dimensions) is used for the all-partner computation. The net-importer conclusion holds under either.
  - **Value vs volume (RESOLVED with a mass analysis):** repeated the import split by **net mass (kg)** alongside value, using **sum-of-bilateral** as the denominator (the World/partner-0 row carries inconsistent netWgt; mass coverage 93–100% of bilateral value). Result: extra-regional = **90.9% by value but 53.0% by mass**; intra-LAC = 47% of tonnage vs 9% of value; extra-regional unit value ~$103/kg vs intra ~$12/kg. `volume_vs_value_2024.csv`. Conclusion: dependence is concentrated in **high-value** (patented/specialty) drugs, not basic volume. Residual caveat: mass ≈ volume but ≠ doses; true production self-sufficiency still needs PAHO/national PRODUCTION data (trade ≠ production).
- **headline_reproduction:** `data/clean/dependency_allpartner_2024.csv` (10 markets × measured extra-regional share = US$29bn floor) + `data/clean/trade_hs30_latest.csv` (28-reporter US$40.2bn import base) recompute the ~US$33bn headline bottom-up; mass-side reproduces from `data/clean/volume_vs_value_kg_2024.csv` (raw bilateral kg). **Two-key:** Codex independently re-derived all of these (see `_insight_log.md` methods-gate Round 2 + the cross-model board; `editorial_review/06_codex_methods.md`).
- **Scenario design:** named, mutually-exclusive coordination scenarios (status quo / subregional blocs / full integration); assumptions table; uncertainty band.
- **Coverage & comparability limits:** Comtrade HS30 self-reports cover **26/33 for 2024 and 28/33 for 2023**; the 5 non-reporters are handled by mirror data; per-indicator coverage declared on every exhibit (N flagged); Caribbean micro-state gaps addressed explicitly.
- **OECD caveat:** any OECD-MCP figure is labeled "OECD members only: CHL/COL/CRI/MEX".

## Cross-model audit adjustments (Codex quant + Agy analytical, 2026-06-04)
- **API metric labeled "EFPIA HS6 API-related basket"** (not "APIs" exactly). Sensitivity: a few broad headings drive Brazil's total (293339 US$1.06bn, 293499 US$0.90bn); excluding broad suspect headings cuts Brazil's API total ~34% but the **China+India share stays ~53–54%** — the concentration claim is robust to basket choice; the absolute $ is basket-sensitive.
- **Typology guardrail:** "Export-oriented formulator" now requires RCA≥0.45 OR (exp/imp≥0.35 AND exports≥US$100m), removing small-volume re-export artifacts (Barbados → micro-importer). Archetype thresholds are transparent heuristics, not empirically calibrated; Argentina sits near the ratio cutoff (0.348).
- **Dominican Republic caveat:** its RCA≥1 reflects US-facing free-zone formulation/enclaves, NOT regionally-mobilizable supply capacity — state explicitly so policymakers don't over-read it.
- **Cuba:** treat as a qualitative case (recognized biotech/vaccine/biosimilar capacity) rather than only "data-opaque," despite the Comtrade reporting gap.

## Latest-state updates (2026-06-07, after comtrade-pharma MCP methodology overhaul)
- **RCA vintage robustness (NEW).** The capability typology's RCA is computed against a WORLD export denominator, and 2024 is an incomplete vintage (the MCP now flags <150 reporters; 2024 summed 136 vs 163 for 2023). Recomputed RCA on BOTH years for the classification-relevant economies: **all archetypes are stable**. DOM stays ≥1 (1.04 / 1.39), the four export-oriented formulators (GTM 0.72/0.76, SLV 0.70/0.77, CRI 0.57/0.62, URY 0.48/0.52) stay ≥0.45, ARG stays <0.45 (0.27/0.38). Stored at `analysis/outputs/capability_rca_robustness.csv`; two-key reproduced by Codex (`research/rca_robustness_codex.md`). The published methodology paragraph now states this.
- **API origin = lower bound (NEW caveat).** Trade records last-consignment country, so APIs transiting EU hubs (Belgium, Netherlands, Ireland, Switzerland — flagged by the MCP `REEXPORT_HUBS`) are credited to the hub, not the Chinese/Indian plant. The ~59% China+India API share is therefore a conservative floor. Added to the API chapter.
- **API basket corroboration.** EFPIA basket now cited alongside the peer-reviewed **CEPII / Cotterlaz et al. (2024)** healthcare-product classification (ref 48), whose "basic pharmaceutical products" branch aligns with it. **Hu et al. (2022)** (ref 49) added to support the mirror/coverage caveats (documents severe Comtrade statistical imbalance in pharmaceuticals).
- **Tariff figures.** The secondary "~14%" Mercosur tariff claim replaced with WTO MFN applied simple averages on HS 30 via the MCP `wto_pharma_tariff` tool (MERCOSUR ≈ 6.7–7.9%, Dominican Republic 0%; ref 50, WTO Stats).
- **Non-reporter mirror fill (NEW, 2026-06-07).** The 5 non-reporters' HS30 imports were reconstructed from partner exports via `comtrade_pharma_mirror_fill` (`data/clean/nonreporter_mirror.csv`): extra-regional addition ~US$0.28B (2024) / ~US$0.27B (2023), <1% of the ~US$33bn headline. A conservative FLOOR (Venezuela and Cuba under-captured by partner reports). Treated as a sensitivity check confirming robustness to the exclusion, NOT a re-anchor. Two-key reproduced by Codex (`research/nonreporter_mirror_codex.md`).
